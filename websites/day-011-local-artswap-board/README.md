# Local ArtSwap Board\n\nA simple static website that lets neighborhood artists and hobbyists list art pieces, crafts, or supplies they want to give away or receive, and discover nearby swaps.\n\n## Features\n- Add a listing with title, description, category, optional image URL and zip prefix.\n- Browse listings with live filters for category and zip prefix.\n- Favorite listings are stored in the browser via `localStorage`.\n- Contact the poster through a pre‑filled `mailto:` link.\n- Fully responsive and works offline after the first load.\n\n## How to run\n1. Clone or download the repository.\n2. Open `index.html` in any modern browser. No server or build step is required.\n\n## Testing manual scenarios\n- **Add listing**: Fill the form, submit, then refresh – the entry should still appear.\n- **Filter**: Choose a category or enter a zip prefix – only matching items stay visible.\n- **Contact**: Click the **Contact** link – your email client should open with a subject containing the listing title.\n\n## Business hypothesis\n- **Target customers**: Local artists, crafters, community centers.\n- **Problem**: Unused art supplies and missed swap opportunities due to lack of a dedicated platform.\n- **Solution differentiator**: Hyper‑local focus, no accounts, visual thumbnails, and free core functionality.\n- **Monetization**: Freemium – premium users can upload images via a third‑party host and get featured placement for a modest monthly fee.\n- **Operating costs**: Currently $0 on GitHub Pages; future costs only if premium features need a tiny backend.\n\n## Limitations\n- Images are loaded via external URLs; no direct upload support yet.\n- Zip filtering only matches the first three digits (simple approximation).\n- No moderation – users must self‑police listings.\n\n## Future improvements\n- Integrate a free image‑hosting API for uploads.\n- Add proper distance calculation using full zip codes.\n- Implement a lightweight moderation queue using GitHub Issues or a static JSON file.\n\n---\n\n*This project is open source and can be deployed directly to GitHub Pages.*
