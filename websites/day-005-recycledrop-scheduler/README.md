# RecycleDrop Scheduler\n\nA static, mobile‑responsive web app that lets neighbourhood residents create, browse, and RSVP to local recycling or bulk‑waste drop‑off events. All data is stored in the browser using `localStorage`, so the site can be hosted for free on GitHub Pages without any backend.\n\n## Features\n- Create an event with title, date, time, location and item categories\n- List upcoming events with attendee count\n- Filter events by category (e.g., electronics, batteries)\n- RSVP to an event; count persists across reloads\n- Works offline after first load (data stays in `localStorage`)\n\n## How to Run\n1. Clone the repository or download the files.\n2. Open `index.html` in any modern browser.\n3. No server needed – all functionality runs client‑side.\n\n## Testing Manual Scenarios\n- **Persistence**: Add an event, close the tab, reopen `index.html`. The event should still be listed.\n- **Filtering**: Type a category name into the filter box; only matching events appear.\n- **RSVP**: Click the RSVP button; the number in parentheses increments and stays after refresh.\n\n## Business Hypothesis\n- **Target customers**: Urban renters, housing co‑ops, and community managers who need a simple way to coordinate waste drop‑offs.\n- **Problem**: Existing social platforms are noisy; dedicated scheduling tools cost money or require logins.\n- **Solution differentiator**: Focused UI, no ads, zero‑login, free tier fully functional.\n- **Monetization**: Offer optional premium packs (custom branding, PDF export) for a small monthly fee once a critical mass of active users is reached.\n\n## Limitations\n- Data is stored locally; events are not shared across devices or users unless they use the same browser.\n- No push notifications – users must keep the page open or rely on manual reminders.\n- Calendar UI is basic (HTML date/time inputs).\n\n## Future Improvements\n- Add a serverless backend to sync events across users.\n- Implement email or browser‑notification reminders.\n- Provide a printable PDF of upcoming events for community bulletin boards.\n\n---\n\n*Free hosting on GitHub Pages keeps operating costs at ₹0 for the prototype.*
