# Neighborhood BookSwap\n\nA static, mobile‑responsive web app that lets neighbors list books, search offerings, and request pickups – all stored locally in the browser.\n\n## Features\n- Add book listings with title, author, condition, and notes.\n- Real‑time search/filter by title or author.\n- Request a pickup; the owner can accept, changing status to **Accepted**.\n- Data persists via `localStorage`; export/import JSON for backup or sharing.\n- Fully responsive and keyboard accessible.\n\n## How to Run\n1. Clone the repo or download the files.\n2. Open `index.html` in any modern browser. No server required.\n\n## Testing Manual Scenarios\n- **Add & Persist**: Fill the form, submit, refresh the page – the book should still appear.\n- **Search**: Type a part of a title; only matching cards remain visible.\n- **Request Pickup**: Click *Request Pickup* on a card, confirm status changes to *Accepted* and button disappears.\n- **Export/Import**: Use the Export button to download `bookswap-data.json`. Clear browser data, then Import the file and verify listings reappear.\n\n## Business Hypothesis\n- **Target**: Residents of apartment complexes, HOAs, and small community groups.\n- **Problem**: Lack of a simple, ad‑free way to coordinate local book exchanges.\n- **Differentiator**: Offline‑first static site – no login, no backend, privacy by design.\n- **Monetization**: Freemium – free core features, paid premium add‑ons (QR labels, custom themes) at $2/month.\n- **Costs**: Hosted free on GitHub Pages; zero ongoing expenses for the prototype.\n\n## Launch Plan\n- Publish to GitHub Pages.\n- Share the link in local community newsletters, Nextdoor posts, and apartment bulletin boards.\n- Collect feedback via a short Google Form linked from the footer.\n\n## Limitations\n- Data is stored only in the user's browser; sharing across devices requires manual export/import.\n- No authentication – anyone using the same browser can modify the data.\n- No real‑time sync; concurrent edits are not coordinated.\n\n---\n\n*This project is a prototype and not a commercial product.*
