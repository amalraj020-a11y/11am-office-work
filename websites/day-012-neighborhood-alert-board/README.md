# Neighborhood Alert Board\n\nA simple, privacy‑first static website for posting and viewing local safety alerts, lost‑pet notices, maintenance updates, and other urgent community information. All data is stored in the browser (localStorage) and can be shared via a URL‑encoded snapshot.\n\n## Features\n- Create alerts with title, description, category, and optional expiration date\n- Filter alerts by category\n- Offline‑first: works without an internet connection after the first load\n- Share the current board state with a single click (generates a link that loads the alerts into any browser)\n- No login, no tracking, fully open source\n\n## Getting Started\n1. Clone the repository or download the files.\n2. Open `index.html` in any modern browser.\n3. Start adding alerts!\n\n## Usage Tips\n- Alerts expire automatically after the chosen date and will no longer appear.\n- The board state is saved in `localStorage`; clearing browser data will remove all alerts.\n- To share a board, click **Share Board**, copy the generated link, and open it in another browser or device.\n\n## Testing Checklist\n- **Create Alert**: Fill the form, submit, and verify the alert appears and persists after refresh.\n- **Filter**: Select a category and confirm only matching alerts are shown.\n- **Delete**: Click the ✖ button on an alert and ensure it disappears.\n- **Share**: Use the share button, open the copied URL in incognito mode, and confirm alerts load correctly.\n- **Expiration**: Set an expiration date in the past and verify the alert is hidden on load.\n\n## Business Hypothesis\n- **Target Customers**: Neighborhood residents, HOA boards, and community‑watch volunteers.\n- **Problem**: Critical local notices get lost in chat groups or printed flyers.\n- **Solution**: A zero‑login, instantly accessible board that anyone can open on a phone.\n- **Monetization**: Free for individuals; optional paid “Community Sponsor” badge for HOAs that want custom branding and a persistent public URL (hypothesized $5/month).\n\n## Limitations\n- Data is stored locally; there is no server‑side persistence or cross‑device sync in the free version.\n- Images are not supported in this prototype (could be added with base64 encoding in a future version).\n- Sharing large numbers of alerts may exceed URL length limits; the prototype is intended for modest daily use.\n\n## Contributing\nFeel free to fork the repo, open issues, or submit pull requests. Enhancements such as password‑protected boards, image uploads, or serverless syncing are welcome.\n\n---\n\n*Built with vanilla HTML, CSS, and JavaScript. Hosted for free on GitHub Pages.*
