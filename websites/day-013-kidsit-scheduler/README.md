# KidSit Scheduler\n\nA simple, static website that helps neighborhoods connect parents with local babysitters. All data is stored in the browser’s `localStorage`, so the app works offline and requires no backend.\n\n## Features\n- Babysitters can register with name, phone, and weekly availability slots.\n- Parents can post a babysitting request (date, start‑time, end‑time).\n- The app matches requests to sitters whose slots fully cover the requested period.\n- Responsive layout works on phones, tablets, and desktops.\n- Accessible forms with proper labels and HTML5 validation.\n\n## How to Use\n1. Open `index.html` in a browser (or deploy to GitHub Pages).\n2. In **Babysitter Sign‑Up**, fill the fields and add one or more availability slots in the format `YYYY-MM-DD HH:MM-HH:MM`. Separate multiple slots with commas.\n3. In **Parent Request**, choose a date and times, then click **Find Sitters**. Matching sitters appear with a click‑to‑call link.\n4. All entries persist across page reloads via `localStorage`. To reset, clear the site data in the browser.\n\n## Development\n- No build step required. Edit `index.html`, `styles.css`, or `app.js` directly.\n- The site is static and can be hosted on any free static host (GitHub Pages, Netlify, Vercel, etc.).\n\n## Business Hypothesis\n- **Target customers**: Parents and babysitters in residential neighborhoods.\n- **Problem**: Existing platforms are either paid, require accounts, or are not localized.\n- **Solution**: A free, local‑only tool that lives in the browser, eliminating fees and privacy concerns.\n- **Monetization**: Offer a optional premium badge for sitters ($2/month) that highlights them at the top of the list. The core product stays free.\n\n## Limitations\n- Data is only stored locally; it does not sync across devices.\n- No background checks or verification – users must trust local community knowledge.\n- No server‑side notifications; contact is via phone link.\n\n## Future Improvements\n- Export/Import JSON backup for data portability.\n- Simple rating/review system stored locally.\n- Email `mailto:` links for request notifications.\n\n---\n\n© 2026 KidSit Scheduler – Open source, free to use.
