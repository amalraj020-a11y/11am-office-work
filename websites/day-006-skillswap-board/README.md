# SkillSwap Board\n\nA simple static website that lets neighborhood residents post skill offers or requests, browse listings, and propose meeting dates. All data is stored locally in the browser (localStorage), so there is no sign‑up, no backend, and no cost.\n\n## Features\n- Add a new skill listing (offer or request)\n- Search by keyword and filter by category\n- Optional price and proposed meeting date\n- Responsive layout for mobile and desktop\n- Data persists across page reloads via localStorage\n\n## Usage\n1. Open `index.html` in any modern browser.\n2. Click **Add Listing**, fill the form, and press **Save**.\n3. The new card appears at the top of the list and stays after refresh.\n4. Use the search box or category dropdown to narrow results.\n\n## Testing Scenarios\n- **Add Listing**: After submitting the form, the listing should be visible and still present after reloading the page.\n- **Search**: Typing a word present in a title or description should hide non‑matching cards.\n- **Category Filter**: Selecting a category shows only listings of that category.\n- **Empty State**: When no listings exist, a friendly message is displayed.\n\n## Business Hypothesis\n- *Target customers*: Urban renters, suburban families, community‑center participants.\n- *Problem*: Lack of a local, low‑friction platform for skill exchange.\n- *Differentiator*: No login, purely client‑side, focused on in‑person barter.\n- *Monetization*: Freemium premium badge ($2/mo) that highlights a listing at the top of search results.\n\n## Operating Costs\n- Hosted for free on GitHub Pages.\n- No server‑side components, so zero ongoing costs.\n\n## Launch Plan\n1. Push the repository to GitHub and enable GitHub Pages.\n2. Share the link in neighborhood Facebook groups, Nextdoor, and community bulletin boards.\n3. Collect feedback from the first 10 users to improve UI and add optional ZIP‑code distance filtering.\n\n## Limitations\n- Data is stored only in the user's browser; listings are not shared across devices or users. This keeps the product free and private but limits network effects.\n- No built‑in messaging; users coordinate meet‑ups outside the platform (e.g., phone, chat).\n- No verification of skill quality or safety; users must exercise typical caution.\n\n## Future Improvements\n- Implement a lightweight JSON‑file sync via GitHub Gist or a free serverless endpoint for shared listings.\n- Add ZIP‑code based distance sorting.\n- Provide QR‑code generation for each listing to post on physical bulletin boards.\n\n---\n\n*This project is a prototype intended for demonstration and early community testing.*
