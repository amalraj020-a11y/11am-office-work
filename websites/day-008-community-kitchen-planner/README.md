# Community Kitchen Planner\n\nA lightweight, static web app that lets residents of a shared‑kitchen community view and book 30‑minute cooking slots. All data is stored locally in the browser (localStorage) with optional JSON export/import for sharing between devices.\n\n## Features\n- Weekly calendar grid (Mon–Sun, 8 AM‑8 PM)\n- Click or press **Enter** on a slot to open a booking dialog\n- Store dish name and optional notes\n- Data persists across page reloads using `localStorage`\n- Export your schedule as a JSON file and import it on another device\n- Fully responsive and keyboard‑accessible\n\n## Usage\n1. Open `index.html` in any modern browser.\n2. Click an empty slot, enter the dish you plan to cook, and hit **Save**.\n3. The slot will display your entry and stay saved after refresh.\n4. Use **Export Data** to download a `kitchen-data.json` file.\n5. On another device, click **Import Data**, select the file, and your schedule will appear.\n\n## Testing Manual Scenarios\n- **Booking a slot**: Select a slot, fill the form, save – the slot shows the dish and remains after reload.\n- **Responsive layout**: Resize the browser to <600 px – the calendar collapses to a single column.\n- **Keyboard navigation**: Tab to a slot and press **Enter** – the booking modal opens.\n\n## Business Hypothesis\n- **Target customers**: Housing co‑ops, community centers, cultural groups with shared kitchens.\n- **Problem**: Uncoordinated kitchen use causes conflicts and wasted time.\n- **Solution differentiator**: Free, offline‑first, no login required, works on GitHub Pages.\n- **Monetization**: Offer a paid “Pro” version that syncs calendars across devices via a low‑cost cloud storage API after the prototype validates demand.\n\n## Limitations\n- Data is stored only in the browser; clearing storage loses the schedule unless exported.\n- No real‑time multi‑user sync – users must share exported JSON files.\n- No authentication or server‑side validation.\n\n## Deployment\n1. Fork the repository.\n2. Enable GitHub Pages on the `main` branch.\n3. The site will be available at `https://<username>.github.io/community-kitchen-planner`.\n\n## Future Improvements\n- iCal/Google Calendar export per user\n- Optional password‑protected cloud sync\n- Dish rating and comment system\n\n---\n*This project is a prototype intended for educational and community‑building purposes.*
