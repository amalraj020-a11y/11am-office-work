# GardenPlot Planner\n\n## Overview\nGardenPlot Planner is a static, mobile‑responsive web app that helps community gardens manage plot reservations, planting notes, and harvest dates without any backend. All data is stored locally in the browser using `localStorage`, making it free to host on GitHub Pages.\n\n## Features\n- Visual grid of 20 plots with occupancy status\n- Claim a plot with name, plant, and expected harvest date\n- Release a plot by clicking on it\n- Persistent data across sessions (localStorage)\n- Optional browser notifications on claim\n\n## Usage\n1. Open `index.html` in a browser (or visit the GitHub Pages URL).\n2. Fill the **Claim a Plot** form and submit.\n3. The plot appears in the calendar grid.\n4. Click a claimed plot to release it.\n\n## Testing\n- **Claim flow**: Submit the form with a free plot number. The plot should turn green and display the owner name.\n- **Persistence**: Refresh the page; the claimed plot should still be visible.\n- **Release flow**: Click a claimed plot, confirm, and ensure it returns to the unclaimed state.\n\n## Business Hypothesis\n- **Target customers**: Community garden coordinators and urban gardeners.\n- **Problem**: Manual sign‑ups cause conflicts and under‑use.\n- **Solution**: Free, offline‑first tool that eliminates paperwork.\n- **Monetization**: Offer a premium pack with PDF export and multi‑garden support for a small subscription.\n- **Operating costs**: Zero while hosted on GitHub Pages.\n\n## Limitations\n- Data is stored per browser; no cross‑device sync unless users export manually.\n- Limited to 20 plots; larger gardens need the premium pack (future).\n- No authentication – suitable for trusted community settings.\n\n## Development\n- No build step required. Edit `index.html`, `styles.css`, or `app.js` and push to GitHub.\n- The site works on any modern browser supporting ES6 and `localStorage`.\n
