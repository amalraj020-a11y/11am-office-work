# Neighbourhood Repair Board\n\n## Overview\nA static, privacy‑first web board for posting small home‑repair requests and offering handyman skills within a neighbourhood. All data is stored locally in the browser (localStorage), so there is no server, no sign‑up, and no tracking.\n\n## Features\n- Post a repair request with title, description, and needed skill\n- Offer a skill to help others (by posting a request with \"I can help\" in the title)\n- Filter requests by skill type\n- Delete your own requests\n- Responsive layout for mobile and desktop\n- Data persists across page reloads\n\n## Usage\n1. Open `index.html` in any modern browser (or visit the GitHub Pages URL).\n2. Fill the form under **Post a Repair Request** and click **Add Request**.\n3. The request appears at the top of the list.\n4. Use the **Filter Requests** dropdown to view specific skill categories.\n5. Click **Delete** on a request to remove it.\n\n## Testing Manual Scenarios\n- **Add request**: Verify the new entry shows up and remains after refreshing the page.\n- **Filter**: Select a skill; only matching requests should be visible.\n- **Delete**: Remove a request and ensure it does not reappear on reload.\n\n## Business Hypothesis\n- **Target customers**: Urban neighbourhood residents and small housing communities.\n- **Problem**: Difficulty finding trusted local help for minor repairs.\n- **Solution differentiator**: No account, no ads, data never leaves the browser.\n- **Monetization**: Freemium – optional paid badge for verified handypeople to increase visibility.\n- **Operating costs**: Zero (static site on GitHub Pages).\n\n## Limitations\n- Data is limited to the device/browser where it is entered; no cross‑device sync.\n- No authentication, so anyone using the same browser can edit/delete all entries.\n- Spam prevention is minimal; future versions could add a simple captcha or export/import feature.\n\n## Future Improvements\n- JSON import/export to share board between devices.\n- Rating system for helpers.\n- Optional anonymous posting with basic spam protection.\n\n## Deployment\n1. Fork this repository.\n2. Enable GitHub Pages on the `main` branch.\n3. The site will be live at `https://<username>.github.io/neighbourhood-repair-board`.\n\n---\n*This product is a prototype and has not been market‑tested.*
