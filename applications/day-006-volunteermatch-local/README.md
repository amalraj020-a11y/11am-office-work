# VolunteerMatch Local\n\n## Overview\nVolunteerMatch Local is a simple static web app that lets community organizers post volunteer slots and local residents browse, filter, and claim them. All data is stored in the browser's localStorage, so the app works offline and requires no backend.\n\n## Features\n- Create volunteer slots with title, description, required skills, date, time, and number needed.\n- Browse slots with live filtering by skill and date.\n- Claim a slot; claims are saved locally and shown in a personal dashboard.\n- Export claimed slots as a CSV file for easy sharing with organizers.\n- Responsive design works on phones, tablets, and desktops.\n\n## Usage\n1. Open `index.html` in any modern browser.\n2. As an organizer, fill the form at the top and click **Add Slot**. The slot appears in the **Available Slots** list.\n3. As a volunteer, use the filter inputs to narrow slots, then click **Claim** on a slot you want.\n4. Your claimed slots appear in the **My Claims** section.\n5. Click **Export CSV** to download a file you can email to the event organizer.\n\n## Technical Details\n- **HTML**: Semantic structure with proper headings and ARIA labels.\n- **CSS**: Simple, mobile‑first layout using Flexbox/Grid.\n- **JavaScript**: Vanilla ES6, uses `localStorage` for persistence, no external libraries.\n\n## Testing Manual Scenarios\n- **Create & Persist**: Add a slot, refresh the page – the slot should still be listed.\n- **Filtering**: Enter a skill keyword and apply filters – only matching slots appear.\n- **Claiming**: Click *Claim* on a slot – it appears in **My Claims**.\n- **CSV Export**: Click *Export CSV* and open the file in a spreadsheet – claim details should be present.\n\n## Business Hypothesis\n- **Target customers**: Small community event organizers and volunteers who need a quick, no‑login solution.\n- **Monetization**: Free tier offers unlimited browsing and claiming. Organizers can pay for a premium add‑on (future) that provides QR‑code check‑in and unlimited slot storage.\n- **Launch plan**: Publish on GitHub Pages, share in local Facebook groups, collect feedback from 2‑3 events, then iterate.\n\n## Limitations\n- Data is stored only in the browser; switching devices loses claims.\n- No authentication – anyone can add slots, so it works best for trusted small groups.\n- No geolocation filtering yet; users must manually enter location info in titles.\n\n## Future Improvements\n- Optional organizer password to hide slots from the public view.\n- Geolocation‑based nearby event filtering.\n- Sync via a lightweight backend for cross‑device claim persistence.\n
