# ShiftSwap Lite\n\n## Overview\nShiftSwap Lite is a static, client‑side web app that lets part‑time and gig workers post, browse, and claim last‑minute shift openings. All data is stored locally in the browser, so no login or backend is required.\n\n## Features\n- Post a shift with date, start/end times, location and optional notes\n- View a list of open shifts and claim them with a single click\n- See your claimed shifts in a separate list\n- Responsive design works on phones, tablets and desktops\n- Data persists across sessions using `localStorage`\n\n## Usage\n1. Open `index.html` in a modern browser (Chrome, Firefox, Edge, Safari).\n2. Fill the **Post a Shift** form and submit – the shift appears under **Open Shifts**.\n3. Click **Claim** on any open shift to move it to **Your Claimed Shifts**.\n4. Reload the page – your shifts remain because they are saved locally.\n\n## Testing Scenarios\n- **Add Shift**: Enter valid data, submit, and verify the shift appears. Refresh – it should still be there.\n- **Validation**: Set end time earlier than start time; the form should show an error.\n- **Claim Shift**: Click **Claim**, the shift disappears from open list and appears in claimed list.\n\n## Business Hypothesis\n- **Target customers**: Retail staff, gig workers, hospitality employees who need flexible scheduling.\n- **Problem**: Missed shift‑swap opportunities cause lost income and scheduling headaches.\n- **Solution differentiator**: No account, zero‑cost, instantly usable on any device.\n- **Monetization**: Free core features; premium filters (distance, skill tags) offered as a low‑cost subscription.\n- **Operating costs**: Currently ₹0 on GitHub Pages; future costs only for optional domain.\n\n## Launch Plan\n1. Publish the repo and enable GitHub Pages.\n2. Share the link in subreddit communities (`r/retail`, `r/gigwork`) and local Facebook groups.\n3. Collect user feedback via a short Google Form linked from the footer.\n\n## Limitations\n- Data is stored only in the browser; switching devices loses information.\n- No real‑time syncing or authentication.\n- Distance filtering not implemented in the prototype.\n\n## Contributing\nFeel free to fork the repo, open issues, or submit pull requests to add features like geolocation, iCal export, or a lightweight backend for optional sync.\n
