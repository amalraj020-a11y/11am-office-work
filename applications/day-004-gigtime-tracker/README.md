# GigTime Tracker\n\n## Overview\nGigTime Tracker is a free, static, offline‑first web app for gig workers and freelancers to log hours, manage clients, and export CSV data for invoicing. All data is stored in the browser's localStorage; no sign‑up or backend is required.\n\n## Features\n- Add clients with hourly rates\n- Create jobs linked to a client\n- Start/stop timers that accumulate hours\n- Edit and delete entries\n- View a summary of earnings per client\n- Export all logged work as a CSV file (compatible with Excel/Google Sheets)\n- Import/Export JSON for manual backup (future improvement)\n\n## Getting Started\n1. Clone or download the repository.\n2. Open `index.html` in any modern browser (desktop or mobile).\n3. Start adding clients and jobs – the app works without an internet connection.\n\n## Testing Manual Scenarios\n- **Add client**: Enter "Acme Corp" and rate "30", click Add. The client appears in the list and the job dropdown.\n- **Add job**: Select the client, type "Logo Design", click Add. The job appears with a Start button.\n- **Timer**: Click Start, wait a few seconds, click Stop. Hours update (e.g., 0.01h) and earnings show in the summary.\n- **Persistence**: Refresh the page; the client and job remain.\n- **CSV Export**: Click "Export CSV" and open the downloaded file; it should contain a header row and one data row matching the logged job.\n\n## Business Hypothesis\n- **Target**: Gig economy workers who need a simple, no‑cost tracking tool.\n- **Monetization**: Free core features; a paid Pro upgrade (PDF invoices, multi‑device sync) at $4/month, aiming for 5% conversion of active users.\n- **Launch**: Publish on GitHub Pages, announce in freelancer subreddits and Discord communities, collect feedback via a short survey.\n\n## Limitations\n- Data is stored only in the browser; clearing storage loses all records.\n- No authentication or cloud sync in the free version.\n- CSV export is basic; no custom templates.\n\n## Future Improvements\n- Dark mode toggle\n- PDF invoice generation\n- Data sync using a low‑cost backend (e.g., Firebase)\n- Import/Export JSON backup feature\n\n---\n*Built with HTML, CSS, and vanilla JavaScript. Hosted for free on GitHub Pages.*
