# Roommate Chore Tracker\n\n## Overview\nA simple offline‑first web app that lets roommates create, assign, schedule, and mark chores as completed. All data lives in the browser's `localStorage`; you can export/import JSON to share between devices.\n\n## Features\n- Add / edit / delete chores\n- Assign chores to any housemate\n- Set daily, weekly, or monthly recurrence\n- Mark chores completed (timestamp shown)\n- Export data as JSON and import back for manual sync\n- Responsive design works on phones and desktops\n\n## Getting Started\n1. Clone or download the repository.\n2. Open `index.html` in any modern browser. No server required.\n\n## Usage\n- Fill the form at the top to add a new chore.\n- Use the **Edit**, **Delete**, and **Done** buttons on each active chore.\n- Completed chores appear in the lower list with a date.\n- **Export JSON** creates a `chores.json` file you can share.\n- **Import JSON** restores a previously exported list.\n\n## Testing Scenarios\n1. **Add chore**: Enter "Take out trash", assignee "Sam", recurrence "Weekly", click Save. The chore appears in Active list.\n2. **Complete chore**: Click **Done**; it moves to Completed with today's date. Because recurrence is weekly, a new identical chore is automatically added.\n3. **Export / Import**: Click Export, then clear browser storage (DevTools > Application > Local Storage). Click Import and select the saved file – the list restores exactly.\n\n## Business Hypothesis\n- **Target**: College and young‑professional shared‑housing markets.\n- **Monetization**: Free core app; a paid Pro tier would add optional cloud sync via a low‑cost backend and custom themes.\n- **Revenue Test**: Offer Pro for $2.99/month; aim for 5% conversion of active users.\n\n## Limitations\n- No real‑time sync; sharing requires manual export/import.\n- Recurrence only creates a new entry after completion; no calendar view.\n- Data is stored locally; clearing browser data will lose information.\n\n## Contributing\nFeel free to open issues or pull requests. Enhancements like QR‑code sharing, email reminders, or analytics are welcome.\n\n## License\nMIT – free to use, modify, and distribute.
