# PetPlaydate Matcher\n\n## Overview\nPetPlaydate Matcher is a static, mobile‑responsive web app that helps urban pet owners create and discover local playdates. All data is stored in the browser’s `localStorage`, so no backend or sign‑up is required.\n\n## Features\n- Create playdate events with title, date, time, pet type, size, and optional tags.\n- Browse events with filters for pet type, size, and keyword.\n- RSVP to events; status is saved locally.\n- Exportable share link (simply copy the page URL).\n\n## Getting Started\n1. Clone or download the repository.\n2. Open `index.html` in any modern browser.\n3. Use the **Create Playdate** form to add events.\n4. Use the **Find Playdates** section to filter and RSVP.\n\n## Testing Manual Scenarios\n- **Create & Persist**: Fill the form, click *Save Playdate*, then reload the page. The event should still appear.\n- **Filtering**: Select *Dog* and *Small* in filters, apply – only matching events show.\n- **RSVP Toggle**: Click *RSVP* on an event; button text changes to *Going* and persists after reload.\n\n## Business Hypothesis\n- **Target**: Urban apartment dwellers with pets, pet clubs, and local sitters.\n- **Problem**: Lack of a simple, privacy‑first tool to arrange pet socialization.\n- **Differentiator**: Zero‑backend, pet‑specific filters, and free open‑source distribution.\n- **Monetization**: Freemium premium add‑on for custom branding and QR‑code export ($2.99/month).\n- **Operating Costs**: Hosted free on GitHub Pages; no server costs.\n\n## Limitations\n- Data is limited to the device/browser; no cross‑device sync.\n- No map integration or image uploads in the prototype.\n- No authentication; anyone with the URL can view and edit local data.\n\n## Future Improvements\n- Add optional Google Maps embed for location.\n- Enable iCal/Google Calendar export.\n- Support image uploads via base64 strings.\n- Optional cloud sync using a lightweight backend (e.g., Firebase) for paid tier.\n\n---\n*This project is intended for educational and prototype purposes only.*
