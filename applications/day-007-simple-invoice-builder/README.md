# Simple Invoice Builder\n\n## Overview\nA lightweight, offline‑first web application that lets freelancers create professional‑looking invoices quickly. All data is stored in the browser’s `localStorage`; no sign‑up or backend required.\n\n## Features\n- Add multiple line items with description, quantity, and rate\n- Automatic subtotal, tax, and total calculation\n- Live preview that can be printed or saved as PDF via the browser\n- Saved invoices persist across sessions\n- Responsive layout works on phones and desktops\n- Keyboard accessible form with validation messages\n\n## Getting Started\n1. Clone the repository or download the files.\n2. Open `index.html` in any modern browser. No build step is required.\n\n## Usage\n1. Fill in client details and at least one line item.\n2. Click **Preview Invoice** – the preview section shows a formatted invoice.\n3. Use the **Print / Save** button to print or save as PDF from the browser.\n4. Invoices are automatically saved; scroll down to **Saved Invoices** to reload any.\n\n## Testing Manual Scenarios\n- **Valid input**: All required fields filled – preview shows correct totals.\n- **Missing required field**: Leaving a required field empty shows an inline error and blocks preview.\n- **Persistence**: After creating an invoice, refresh the page – the invoice appears in the Saved list and can be loaded.\n\n## Business Hypothesis\n- **Target**: Freelancers, gig workers, and small consultants who need quick invoices without paying for SaaS.\n- **Monetization**: Free core functionality; after a threshold (e.g., 100 invoices per year) offer a paid PDF export or branding feature.\n- **Costs**: Hosted on GitHub Pages – essentially zero cost.\n\n## Limitations\n- No actual PDF generation – relies on browser print dialog.\n- Data is limited to the device/browser; clearing storage removes invoices.\n- No multi‑user sharing or cloud backup in the free version.\n\n## Roadmap\n- Integrate `jsPDF` for true PDF download.\n- Add custom logo/branding fields.\n- Optional Google Drive backup via OAuth (future paid tier).\n\n---\n\n*This project is a prototype intended for educational and validation purposes.*
