# FamilyMeal Planner\n\n## Overview\nFamilyMeal Planner is a static, offline‑first web application that helps households plan weekly meals, assign cooking duties, and generate a grocery list. All data is stored locally in the browser (localStorage) – no sign‑up, no ads, no external servers.\n\n## Features\n- Weekly grid for 7 days × 3 meals (breakfast, lunch, dinner)\n- Click a cell to add/edit meal name and assign a family member\n- Auto‑generated grocery list based on entered meals (simple word split)\n- Data persists across sessions via `localStorage`\n- Responsive layout for mobile and desktop\n- Accessible: keyboard navigation (Enter key) and proper labels\n\n## Getting Started\n1. Clone or download the repository.\n2. Open `index.html` in any modern browser. No build step required.\n3. Click on any meal cell, enter the dish name and who will cook.\n4. Press **Generate Grocery List** to see a consolidated list of ingredients.\n\n## Testing Manual Scenarios\n- **Add meals**: Click Monday Breakfast, enter `Pancakes` and `Alice`. Verify the cell shows the name and cook.\n- **Persistence**: Refresh the page; the entered data should remain.\n- **Grocery generation**: Add `Spaghetti Bolognese` on Tuesday Dinner, then generate the list. Expect items like `spaghetti`, `bolognese` to appear.\n\n## Business Hypothesis\n- **Target customers**: Busy families, roommates, co‑living communities.\n- **Problem**: Coordination overhead leads to repeated meals and food waste.\n- **Differentiator**: Fully offline, no login, free core features.\n- **Monetization**: Freemium – premium PDF export and optional encrypted cloud backup for a small monthly fee.\n- **Launch plan**: Deploy on GitHub Pages, share in parenting and roommate subreddits, collect feedback, iterate.\n\n## Limitations\n- Grocery list generation is naïve – it treats each word as an ingredient.\n- No real recipe database integration (can be added later).\n- Premium features not implemented in this prototype.\n\n## Contributing\nFeel free to fork the repo and submit pull requests. Improvements such as recipe import, better pantry tracking, or cloud sync are welcome.\n\n---\n*This project is a prototype intended for educational purposes and does not collect any personal data.*
