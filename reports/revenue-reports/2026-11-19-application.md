# Revenue hypothesis — Roommate Chore Tracker

- **Model:** freemium
- **Pricing hypothesis:** Offer a paid "Pro" version that adds cloud sync via a low‑cost third‑party storage API and custom themes; 5% of active users may upgrade at $2.99/month.
- **Free tier:** All core features remain free; no ads, no data collection.
- **Free hosting:** GitHub Pages

## Potential operating costs

- Current prototype: ₹0 within published free-tier limits

## Potential customers

- University housing offices
- Co‑living startup incubators
- Student housing Facebook groups

## Launch strategy

- Publish repository on GitHub with GitHub Pages enabled
- Share the link in university housing forums and Reddit r/roommates
- Collect feedback via a short Google Form and iterate
