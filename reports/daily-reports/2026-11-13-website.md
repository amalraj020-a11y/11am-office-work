## Problem

Urban community gardens struggle with manual sign‑ups, overlapping plot reservations, and lack of clear communication about plot availability and maintenance schedules.

## Solution

A lightweight, mobile‑responsive web app that lets garden members view, claim, and release garden plots, track planting cycles, and receive reminders, all stored locally for zero‑cost hosting.

## Target customers

- Community garden coordinators
- Urban residents with garden plots
- Neighborhood associations

## Features completed

- View a calendar of all garden plots with current occupancy
- Claim or release a plot with a simple form
- Add planting notes and expected harvest dates
- Automatic local reminders via browser notifications
- Responsive design for phones and tablets

## Technologies

- CSS
- JavaScript
