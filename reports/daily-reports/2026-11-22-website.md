- **Project:** `websites/day-009-microevent-rsvp`

## Problem

Small community groups (HOAs, clubs, hobby circles) need a simple way to announce one‑off events, collect RSVPs, manage waitlists and share details without paying for complex ticketing platforms or relying on fragmented group chats.

## Solution

A lightweight, mobile‑responsive static website that lets organizers create an event page, set a capacity, and lets visitors RSVP instantly. Data is stored locally in the browser (localStorage) so the site works fully offline and costs nothing to host.

## Target customers

- Neighborhood associations
- Club organizers
- Local hobby groups
- Community centers

## Features completed

- Create an event with title, description, date, time, location and capacity
- RSVP form with name and email validation
- Automatic waitlist when capacity is reached
- LocalStorage persistence – data survives page reloads and works offline
- Responsive design for phones and desktops
- Accessible form fields and keyboard navigation

## Technologies
