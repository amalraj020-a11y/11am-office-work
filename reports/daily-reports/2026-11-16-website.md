## Problem

Neighborhoods often have periodic recycling or bulk waste collection days, but residents lack a simple way to coordinate extra drop-offs for items like electronics, batteries, or large furniture, leading to missed pickups or illegal dumping.

## Solution

A lightweight, mobile‑responsive static web app where residents can post, view, and sign up for local recycling drop‑off events, filter by item type, and receive browser notifications. All data is stored locally so the site can be hosted for free on GitHub Pages.

## Target customers

- Urban renters and homeowners who want to responsibly dispose of bulk or hazardous waste
- Community association managers looking to promote organized recycling

## Features completed

- Create a drop‑off event with date, time, location, and item categories
- Browse upcoming events on a list or simple calendar view
- RSVP to events; attendees count is shown
- Filter events by item type (electronics, batteries, furniture, etc.)
- Data persisted in localStorage for offline access
