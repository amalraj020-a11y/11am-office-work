# 2026-11-27 — Neighborhood Alert Board

- **Mission:** website
- **Project:** `websites/day-012-neighborhood-alert-board`
- **Deployment:** attempted only after validation

## Problem

Residents often learn about local safety issues, lost pets, or urgent community notices too late because information is scattered across group chats, flyers, or word of mouth, leading to missed opportunities to help or stay safe.

## Solution

A lightweight, mobile‑responsive static website where anyone can post short alerts (e.g., lost pet, road hazard, neighborhood watch tip) that are saved locally and can be shared via a simple URL. The board shows the most recent alerts, allows filtering by category, and works offline using localStorage.

## Target customers

- urban and suburban neighborhood residents
- HOA boards
- community safety volunteers

## Features completed

- Create, edit, and delete alerts with title, description, category, and optional expiration date
- Filter alerts by category (Lost Pet, Safety, Maintenance, Other)
- Responsive design works on phones and desktops
- All data stored in browser localStorage for privacy and offline use
- Shareable URL that loads the current board state via URL‑encoded data

## Technologies

- HTML
- CSS
- JavaScript

## Competitor notes

- Nextdoor: Nextdoor requires account creation and aggregates many types of posts; our board is zero‑login, privacy‑first, and focused solely on urgent alerts. (no URL; human verification required)
- Patch: Patch is a news platform for towns; it lacks real‑time, user‑generated safety alerts and offline capability. (no URL; human verification required)

## Test scenarios

- Use the share button, copy the generated URL, open it in a new incognito window, and confirm the alert list loads from the URL parameter.
- Apply a category filter and ensure only matching alerts are displayed.
