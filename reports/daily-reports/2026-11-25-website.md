## Problem

Artists and hobbyists in neighborhoods often have extra artwork, crafts, or supplies they want to exchange, but lack a simple, local platform to list items, discover nearby swaps, and arrange meetups, leading to wasted materials and missed community connections.

## Solution

A lightweight static website where users can post items they want to give away or receive, filter listings by distance and category, and coordinate swaps via contact forms, all without requiring accounts or server-side processing.

## Target customers

- Neighborhood artists
- Hobby crafters
- DIY enthusiasts
- Community centers

## Features completed

- Create a listing with title, description, category, and optional image URL
- Filter listings by category and distance (using zip code prefix)
- Save favorite listings in localStorage
- Contact poster via prefilled mailto link
- Responsive mobile‑first design

## Technologies

- HTML
- CSS
- JavaScript

## Competitor notes

- Freecycle: Freecycle is global and unstructured; our board focuses on hyper-local art exchanges with category filters and visual thumbnails. (no URL; human verification required)
- Nextdoor Marketplace: Nextdoor is a broad neighborhood marketplace; we specialize in art/supply swaps with no ads and a simple swap‑focused UI. (no URL; human verification required)
