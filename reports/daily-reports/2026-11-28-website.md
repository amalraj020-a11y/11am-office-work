## Problem

Parents need reliable, nearby babysitters but rely on word‑of‑mouth, group chats, or paid platforms, leading to last‑minute gaps, safety concerns, and wasted time.

## Solution

A lightweight, mobile‑responsive static website where neighborhood babysitters can list their availability and parents can request a sitter. All data is stored locally in the browser, enabling quick offline use without any backend.

## Target customers

- Parents of children aged 0‑12 in residential neighborhoods
- Local babysitters looking for nearby gigs

## Features completed

- Babysitter sign‑up with name, contact, and weekly availability slots
- Parents can post a babysitting request specifying date, time, and child age
- Automatic matching of requests to available sitters
- Local storage persistence so data survives page reloads
- Responsive design for mobile and desktop
- Accessible forms with keyboard navigation and validation

## Technologies

- HTML
- CSS
- JavaScript
