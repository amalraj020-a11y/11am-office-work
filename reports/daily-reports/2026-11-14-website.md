# 2026-11-14 — Neighborhood BookSwap

- **Mission:** website
- **Project:** `websites/day-003-neighborhood-bookswap`
- **Deployment:** attempted only after validation

## Problem

Residents in small neighborhoods want to exchange books locally but lack a simple way to list, request, and schedule pickups, leading to missed sharing opportunities and cluttered group chats.

## Solution

A lightweight static web app where users can post books they offer, browse nearby offers, send pickup requests, and track pending exchanges, all stored in the browser with optional export/import for persistence.

## Target customers

- Urban apartment dwellers
- Suburban neighborhood groups
- Community library volunteers

## Features completed

- Add a book listing with title, author, condition, and optional photo
- Search and filter listings by title or genre
- Request a pickup; the owner can accept or decline
- Local storage of all data; export/import JSON for backup or sharing
- Responsive design for mobile and desktop

## Technologies

- HTML
- CSS
- JavaScript

## Competitor notes

- BookCrossing: Focuses on global tracking; no neighborhood‑only UI or simple static hosting. (no URL; human verification required)
- Nextdoor: General social platform; no dedicated book‑swap workflow or offline‑first design. (no URL; human verification required)
