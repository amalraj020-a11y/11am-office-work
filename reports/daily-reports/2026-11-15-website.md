## Problem

Neighborhood residents and small community groups have no easy way to announce one-time local events (block parties, garage sales, pop‑up classes) and collect RSVPs without relying on group chats or paper flyers, leading to low attendance and missed connections.

## Solution

A lightweight, mobile‑responsive static web app that lets anyone create a public event card, set date, time, location and limit, and share a short URL. Visitors can RSVP, see who else is attending, and the organizer can edit or delete the event. All data is stored locally in the browser, so no backend is required.

## Target customers

- Residents of apartment complexes or small neighborhoods
- Community organizers of local pop‑up events
- Small NGOs running neighborhood workshops

## Features completed

- Create event with title, description, date, time, location and optional attendee limit
- Generate shareable short URL (hash‑based) that loads the event from localStorage
- RSVP with name and optional note, view attendee list
- Edit or delete own event via a simple password stored locally
- Responsive design, keyboard navigation, form validation and empty states
