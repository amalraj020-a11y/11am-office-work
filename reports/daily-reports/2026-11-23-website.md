# 2026-11-23 — Neighbourhood Repair Board

- **Mission:** website
- **Project:** `websites/day-010-neighbourhood-repair-board`
- **Deployment:** attempted only after validation

## Problem

Residents often need quick help for small home repairs (plumbing, electrical, carpentry) but lack a trusted local platform to post requests and find nearby handypeople, leading to reliance on costly services or unreliable word‑of‑mouth referrals.

## Solution

A lightweight, offline‑first web board where users can post repair requests, specify skills they offer, and match locally without any backend. All data stays in the browser via localStorage, ensuring privacy and zero hosting cost.

## Target customers

- Urban neighbourhood residents
- Apartment complex occupants
- Small housing co‑ops

## Features completed

- Post a repair request with title, description, and needed skill
- Offer a skill to help others
- Filter requests by skill type
- Persist data locally so board survives page reloads
- Responsive design for mobile and desktop

## Technologies

- HTML
- CSS
- JavaScript

## Competitor notes

- Nextdoor: Broad social network; no focused repair‑request board, requires account and ads (no URL; human verification required)
- TaskRabbit: Paid service connecting to freelancers; no free local board and incurs fees (no URL; human verification required)

## Test scenarios

- Add a new repair request → it appears at the top of the list and persists after page reload
- Apply a skill filter → only requests needing that skill remain visible
- Delete a request → it disappears and does not reappear on reload

## Next improvements

- Add optional export/import of board data as JSON for sharing between devices
- Implement a simple rating system for helpers
- Allow anonymous posting with a simple captcha to reduce spam
