## Problem

Neighborhoods with shared community kitchens often face chaotic scheduling, overlapping bookings, and lack of visibility into available cooking slots, leading to underutilized resources and conflicts among residents.

## Solution

A simple static web app that lets residents view a weekly calendar of kitchen slots, claim a slot, add a dish description, and see who else is cooking, all stored locally with optional export for offline sharing.

## Target customers

- Residents of housing complexes or co‑ops with a shared kitchen
- Community organizers managing communal cooking events

## Features completed

- Weekly calendar view with 30‑minute slots
- Slot claim with dish name and optional notes
- LocalStorage persistence and export/import JSON
- Responsive design for mobile and desktop
- Accessible keyboard navigation and ARIA labels

## Technologies

- HTML
- CSS
- JavaScript

## Test scenarios

- Open the site, click an empty slot, enter a dish name, and save – the slot should display the dish and persist after refresh.
- Resize the browser to mobile width – the calendar should reflow into a single column and remain usable.
- Use keyboard Tab to focus a slot and press Enter – the claim dialog opens, confirming keyboard accessibility.
