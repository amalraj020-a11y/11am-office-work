## Problem

Urban residents and commuters often struggle to find safe, affordable short‑term parking near their destination, while homeowners with unused driveway space have no easy way to advertise and monetize those spots.

## Solution

A lightweight, static web app that lets users list, browse, and reserve nearby driveway or curbside parking spots for a few hours or a day, storing data locally for demo purposes and allowing export/import of listings.

## Target customers

- Urban commuters
- Homeowners with spare driveway space
- Apartment complex managers

## Features completed

- Create a parking spot listing with address, time window, price, and optional photo URL
- Search listings by ZIP code and date range
- Reserve a spot (stores reservation in localStorage)
- Export and import listings as JSON for simple data persistence
- Responsive design for mobile and desktop

## Technologies

- HTML
- CSS
- JavaScript

## Competitor notes

- SpotHero: SpotHero relies on paid integrations with garages; StreetSpot Share is community‑driven, free, and runs entirely on static hosting. (no URL; human verification required)
- ParkWhiz: ParkWhiz aggregates commercial lots; our focus is residential curbside spots and peer‑to‑peer sharing. (no URL; human verification required)

## Test scenarios

- Create a new listing, then refresh the page – the listing persists via localStorage.
- Search for a ZIP code with no listings – the UI shows an empty state message.
- Reserve a spot and then reload – the reservation remains stored and is reflected in the UI.
