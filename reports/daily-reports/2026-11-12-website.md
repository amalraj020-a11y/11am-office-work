- **Project:** `websites/day-001-toolshare-scheduler`
- **Deployment:** attempted only after validation

## Problem

Neighborhoods often have shared tool libraries or community tool sheds, but coordinating reservations, availability, and maintenance is done manually via paper logs or group chats, leading to conflicts and under‑use.

## Solution

A lightweight, mobile‑responsive static web app that lets residents view, reserve, and return tools in a community shed. All data is stored locally per user and can be exported/imported as JSON for the caretaker, eliminating the need for a server.

## Target customers

- Residents of housing societies with shared tool sheds
- Community association caretakers

## Features completed

- View list of tools with availability status
- Reserve a tool for a specific date range
- Mark tool as returned
- Export and import full inventory JSON for caretaker backup
- Responsive design for phones and tablets

## Technologies

- HTML
- CSS
- JavaScript

## Competitor notes

- Nextdoor: General neighborhood social platform, no dedicated tool reservation UI (no URL; human verification required)
- ShareTool: Requires cloud subscription and user accounts; our app runs entirely on static hosting (no URL; human verification required)

## Test scenarios

- Open the site, click 'Add New Tool', fill name and quantity, save – the tool appears in the list.
- Reserve a tool for tomorrow, close the browser, reopen – reservation persists via localStorage.
- Mark the tool as returned – status changes back to 'Available'.
