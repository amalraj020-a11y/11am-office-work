# 2026-11-19 — SkillSwap Board

- **Mission:** website
- **Project:** `websites/day-006-skillswap-board`
- **Deployment:** attempted only after validation

## Problem

Neighborhood residents often have useful skills (e.g., guitar lessons, gardening help, coding tutoring) but lack a simple, local platform to advertise, discover, and schedule skill exchanges, leading to missed learning opportunities and underutilized talent.

## Solution

A lightweight static website where users can post skill offers or requests, browse nearby listings, and arrange meet‑ups via a built‑in calendar. All data is stored locally in the browser, keeping it free, private, and instantly usable without sign‑up.

## Target customers

- Urban renters
- Suburban families
- Community center members

## Features completed

- Post a skill offer or request with description, category, and optional price
- Search and filter listings by category and distance (based on ZIP code)
- Add a proposed meeting date/time via an interactive calendar widget
- Save favorite listings and view scheduled meet‑ups
- Responsive design for mobile and desktop

## Technologies

- HTML
- CSS
- JavaScript

## Competitor notes

- Nextdoor: Nextdoor is a broad social network; SkillSwap focuses solely on skill exchange with simple scheduling and no login. (no URL; human verification required)
- Meetup: Meetup organizes groups/events; SkillSwap is a personal one‑to‑one barter board with calendar integration. (no URL; human verification required)
- Skillshare (online): Online classes, not local in‑person exchanges; SkillSwap connects neighbors for face‑to‑face learning. (no URL; human verification required)
